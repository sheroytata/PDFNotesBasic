Privacy Policy

PDF Notes Basic does not collect user data. The app accesses PDF files only when you choose to open or import them.

Last updated: 29 October 2026

1. Privacy at a glance

PDF Notes Basic is a PDF viewing, annotation, and editing app for iPad. The app does not collect personal information or other user data. It does not require an account, run advertising or tracking, or send documents and annotations to the developer.

2. Access to your documents

You decide which files to work with. PDF Notes Basic accesses a PDF only when you explicitly select, open, import, or share it with the app through iPadOS file-selection or sharing controls. It does not independently browse, scan, or access your other files.

Files you have not selected are not accessible to the app simply because they are stored on your device.

3. Cloud storage

PDF Notes Basic has no direct connection to cloud storage services and does not independently access iCloud Drive or third-party cloud accounts. If you choose a document from a location provided by the Files app, iPadOS and the storage provider you selected may download or synchronize that document to fulfill your request. That activity is controlled by the operating system and the provider, not by a built-in PDF Notes Basic cloud service.

4. Editing, saving, and sharing

PDF content and annotations are processed by the app for the editing actions you request. When you save or export a document, you choose the destination using the available iPadOS controls. The app does not automatically upload your PDFs, notes, or exported documents to developer-operated servers.

5. Analytics and tracking

PDF Notes Basic does not collect app usage analytics, advertising identifiers, contact details, or other user data for the developer. It does not include a developer-operated analytics, tracking, or cloud-sync service.

6. Website and GitHub Issues

This policy describes the PDF Notes Basic app. Its separate support website is hosted on GitHub Pages, and optional bug reports and feature requests use GitHub Issues. If you choose to visit the website or submit an issue, GitHub may process technical information and any content you voluntarily provide under GitHub's Privacy Statement.

GitHub Issues are public. Do not publish private PDF files, credentials, confidential notes, or other sensitive information in reports or attachments. Using GitHub Issues requires a GitHub account; it is not required to use PDF Notes Basic.

7. Questions about privacy

For questions about this policy, use the GitHub issue forms. Posts made there are public. No email address is required or displayed on this website.

8. Changes to this policy

If PDF Notes Basic's data practices change, this page will be updated and the last-updated date will be revised.
