Common questions

How do I open a PDF?

Use the Open control and select a document from the iPad Files app.

How can I move or duplicate PDF pages?

Open Pages to view thumbnails and switch to Edit mode for page organization.

How do I save annotations?

Use the app's PDF save/export controls. For selected-page exports, flattening is an optional setting.

Can I attach screenshots to a bug report?

Yes, but remove personal details first. Remember that GitHub Issues and their attachments are public.
